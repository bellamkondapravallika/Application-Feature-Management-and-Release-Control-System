# Frontend

The frontend is built using React and Vite to provide a modern and responsive dashboard for managing feature flags. It allows administrators to create and manage feature flags, configure environment overrides, manage user and group targeting, configure percentage rollouts, monitor Redis cache status, and test feature flag evaluations through an intuitive interface.

## Technologies
- React
- Vite
- Tailwind CSS
- Framer Motion
- Axios

## Run the Frontend

```bash
npm install
npm run dev
```

Application URL:
http://localhost:3000
